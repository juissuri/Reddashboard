# Reddashboard 🔴🖤

**Reddashboard** is a sleek, dark-themed command center and Kanban-style project management plugin designed for Obsidian. Built with a striking red-and-black aesthetic, it helps you structure complex creative pipelines, track daily progress, and stay laser-focused on your goals.

![Reddashboard Overview](path-to-screenshot.png)

---

## ✨ Key Features

* **🎨 Immersive Dark Aesthetic:** Designed with a strict, distraction-free red-and-black color palette tailored for modern workflows.
* **📊 Global Productivity Panel:** Get an instant overview of your efficiency with a built-in 7-day trend chart and key performance metrics (active projects, open tasks, and daily completions).
* **🎯 Folder-Based Workspaces & Mini-Donuts:** Organize your work into dedicated project folders equipped with real-time circular progress rings.
* **⚡ Interactive Segmented Progress Bars:** Fine-tune your task completion segment-by-segment (0% to 100%) with visual feedback and glowing active markers.
* **🏷️ Pipeline Stage Badges & Tags:** Track your production stages (e.g., `#Blockout`, `#UV`, `#UE5`) and filter tasks instantly with reactive tag-clicking.
* **🔍 Global Search & Filtering:** Quickly locate any task across your entire vault using the reactive title search bar.
* **🗂️ Drag-and-Drop Organization:** Effortlessly rearrange your project cards on the main screen—your custom layout persists automatically via `data.json`.
* **🔗 Sidebar Quick Links:** Jump straight to your core notes, asset vaults, or key directories with a minimalist vertical toolbar.

---

## 🚀 Getting Started

### Installation via BRAT (Beta Reviewers Auto-Update Tool)
1. Ensure you have the **BRAT** plugin installed in Obsidian.
2. Add this GitHub repository URL (`your-username/reddashboard`) to BRAT.
3. Enable **Reddashboard** in your Obsidian community plugin settings.
